# Data Licenses

The Apache-2.0 license in this repository applies to repository source code unless a file states otherwise. It does not relicense third-party or government datasets.

## Taiwan government open data
Datasets imported from Taiwanese government open-data portals remain subject to the license and attribution requirements stated by each source, commonly the Taiwan Open Government Data License (OGL) 1.0. Preserve required attribution and source metadata.

## Google Maps Platform
Google Maps / Places data and services are governed by Google Maps Platform terms. They are not Apache-2.0 data and must not be exported or relicensed as project-owned parking data.

## OpenStreetMap (future, if used)
OSM-derived database content is governed by ODbL and must be handled separately from repository source-code licensing.

Every new data adapter must document its source URL, license/terms, attribution text, refresh policy, and any redistribution/storage restrictions before production ingestion is enabled.
